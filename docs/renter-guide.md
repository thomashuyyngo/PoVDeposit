# Renter guide

1. Install Freighter or Rabet and select Stellar Testnet.
2. Obtain only Testnet assets from the documented faucet/process.
3. Connect the extension; never enter a recovery phrase in the app.
4. Select an approved property and unreserved viewing slot.
5. Read the amount, asset, deadlines, fee and Template A outcome.
6. Sign the create/fund transactions and wait for backend event confirmation.
7. At the appointment, scan the short-lived QR or request the accessible manual code.
8. Confirm attendance, cancel within the displayed rule, or open an eligible dispute.
9. Follow the explorer link for refund/release settlement.

Wrong network, expired slot lock, rejected signature, failed transaction and expired/used QR states do not advance the booking.
