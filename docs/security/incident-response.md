# Incident response

1. Pause creation of new bookings without blocking valid settlements.
2. Preserve transaction IDs, logs and affected revisions without copying secrets.
3. Revoke sessions and rotate compromised API/storage/role credentials.
4. Reconcile database records against contract events.
5. Patch, test and deploy through protected CI.
6. Notify affected participants with verified facts and publish a post-incident review.
